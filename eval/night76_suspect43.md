- 对象: Night 74 审计「存疑」43 条（eval/night74_lexicon_audit.md §3.2 / verdicts 缓存底稿）。本夜 backend 一字未改，只出结论。
- 方法（N75 舎案的方法）: ①语料实例（golden_8165 的書き下し文送り仮名分布＋语料出处页 kanbun.info 的振り仮名 62 页，与 golden source_url 同源）＞ ②辞書（N74 verdicts 底稿＋weblio 補查 5 页：失す/過ぐ/矣/弗/奚）＞ ③活用形/訓読慣用。
- 判定口径: `確認OK`＝语料实例（含出处页振り仮名）支持现状；`要修正`＝语料/辞書证据给出具体改法；`仍存疑`＝语料有实例但无法裁决；`语料无实例`＝词形（含变体）在 golden_8165 中 0 命中。

## 本夜新知（供后续参考）

1. **语料出处页振り仮名是最强证据**：golden_8165 无 ruby，但 kanbun.info 源页有完整 `<ruby>`。N74 型「语料の振り仮名照合を推奨」存疑从此有了系统解法（62 页一括抓取，tools/night76_ruby_fetch*.py）。
2. **N74 的一条建议被语料推翻**：未（idx494）的词库读法「いま」与出处页振り仮名「未=いま（＋だ）」完全一致，N74 提议改「いまだ」不需要做——词库语干表记设计与语料 ruby 约定同构。
3. **N74 底稿的噫/喪ぼす evidence 互换**：idx172（噫）挂的是喪ぼす的辞書证据、idx171（喪ぼす）挂的是噫的。本夜用 aatenware 页 ruby（噫=ああ）实証噫=ああ，互换已在 JSON 中修正记录。
4. **行内振り仮名行**：少数 golden 行 kkd 自带（…）式振り仮名（sanryaku03-3/utsuryo10-2/rikutou34-7 等 bun 侧、sanryaku03-3 也在 kkd 侧）。这类行会破坏词形匹配（「釈（す）てて」≠「釈て」）——词库命中统计的已知噪声源，另案。
5. **词库覆盖缺口（新观察，不在 43 条内）**：kkd 保持形「而る後」（19 例，読み しかるのち）与「而ち」（8 例，読み すなわち）没有专条目；サ変「利す（りす）」（老子/孫子，利=り）与形容词「利し（とし）」是两个词，现只有后者。
6. **N75 舎案再证**：釈て=すて 与舎つ=すつ 同属语料慣用优先于辞書训欄的案例；出处页振り仮名一括核对后，这一原则适用面比预想大得多（洎=およ、樹=う、壁=へき 等都是辞书训欄查不到的读法）。
